# Prachi — एक मनापासूनची गोष्ट

A small static Marathi letter, ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository and add `index.html` and `style.css` at its root.
2. Push the files to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published site URL in the Pages section.

The page uses Google Fonts when internet access is available and falls back to system fonts otherwise.
